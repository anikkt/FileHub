# FileHub

FileHub is an open-source personal and team document portal built with React, TypeScript, and Firebase.

## Setup Instructions

1. Push this entire repository to GitHub.
2. In your GitHub repository settings, go to **Settings > Secrets and variables > Actions**.
3. Add repository secrets for each `VITE_FIREBASE_*` variable.
4. Go to **Settings > Pages** and set **Source** to **GitHub Actions**.
